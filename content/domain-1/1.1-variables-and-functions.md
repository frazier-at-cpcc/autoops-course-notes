### Variables and scope
- A ==variable== is a name bound to a value: `hostname`, `vlan_id`, `retries`
  - Change the value in one place; every line that uses it follows
- Syntax: Python `vlan = 20`; PowerShell `$vlan = 20`; Bash `vlan=20` (no spaces around `=`), read as `"$vlan"`
  - Bash stores everything as a string; math needs `$(( vlan + 1 ))`
- ==Scope== decides which parts of a script can see a variable
  - ==Global==: defined at the top level of the script; readable from every function
  - ==Local==: created inside a function; gone when the function returns
  - A name not found locally is looked up in the global scope

:::figure 1.1-variable-scope.svg | A function sees its own locals first, then globals. Nothing outside the function can see its locals.

- Python: assigning inside a function creates a local
  - To change a global, declare `global retries` first; without it, `retries += 1` fails with `UnboundLocalError`
- Bash: the opposite default
  - Every variable is global, even one set inside a function
  - Declare `local` so a function cannot overwrite the caller's values
- PowerShell: functions get a child scope; write back with `$script:name` or `$global:name`

```python label="scope.py"
retries = 3                  # global

def connect(host):
    timeout = 5              # local to connect()
    return (f"{host} retries={retries} "
            f"timeout={timeout}")

def bump():
    global retries           # rebind the global
    retries += 1

print(connect("core-sw1"))
bump()
print(connect("core-sw1"))
print(timeout)               # not visible here
```

```console label="Terminal"
$ python3 scope.py
core-sw1 retries=3 timeout=5
core-sw1 retries=4 timeout=5
NameError: name 'timeout' is not defined
```

### Conditional statements
- ==Conditional statements== run a block only when a test is true
  - `if`, optional `elif` (Python, Bash) or `elseif` (PowerShell), optional `else`
  - Multi-way: `case` in Bash, `match` in Python 3.10+, `switch` in PowerShell
- In Bash the condition is a command's ==exit status==
  - `0` means true (success); anything else means false
  - `if grep -q shutdown sw1.cfg; then` branches on whether grep matched
- Python truthiness: `0`, `""`, `[]`, `{}`, and `None` count as false

:::wide
| Test | Python | Bash | PowerShell |
|---|---|---|---|
| Numbers equal | `a == b` | `[[ $a -eq $b ]]` | `$a -eq $b` |
| Strings equal | `a == b` | `[[ $a == "$b" ]]` | `$a -eq $b` (ignores case); `-ceq` matches case |
| Greater than | `a > b` | `[[ $a -gt $b ]]` | `$a -gt $b` |
| And / or / not | `and`, `or`, `not` | `&&`, `\|\|`, `!` | `-and`, `-or`, `-not` |
| File exists | `os.path.exists(p)` | `[[ -f $p ]]` | `Test-Path $p` |
:::

### Iterations
- An ==iteration== (loop) repeats a block: one block, 400 switches
- A ==for loop== walks a known collection: hosts, VLANs, files, lines of output
- A ==while loop== repeats until a condition changes: poll a service, retry a login
  - Always cap the attempts so a dead host cannot hang the pipeline
- `break` leaves the loop; `continue` skips to the next item
- Bash `while read -r line; do ...; done < hosts.txt` reads a file line by line

```bash label="check_hosts.sh"
#!/usr/bin/env bash
# Report which inventory hosts answer on a TCP port
PORT=${1:-22}             # parameter, default 22
HOSTS=(127.0.0.1 127.0.0.2 192.0.2.10)
up=0                      # global counter

probe() {                 # $1 = host, $2 = port
  local host=$1 port=$2
  timeout 1 bash -c "</dev/tcp/$host/$port" \
    2>/dev/null
}

for h in "${HOSTS[@]}"; do
  if probe "$h" "$PORT"; then
    echo "$h:$PORT up"
    up=$((up + 1))
  else
    echo "$h:$PORT down"
  fi
done
echo "$up of ${#HOSTS[@]} hosts up"
```

```console label="Terminal"
$ ./check_hosts.sh 18100
127.0.0.1:18100 up
127.0.0.2:18100 down
192.0.2.10:18100 down
1 of 3 hosts up
```

### Parameters and functions
- A ==function== is a named, reusable block: write the logic once, call it for every device
- ==Parameters== are the inputs a function declares; ==arguments== are the values passed in a call
  - Positional: matched by order (`probe "$h" "$PORT"`)
  - Keyword or named: matched by name (`attempts=2`, `-Vlan 20`)
  - A default value makes a parameter optional
- Return values
  - Python and PowerShell return objects to the caller
  - A Bash function returns only an exit status (0 to 255); print data with `echo` and capture it with `$(...)`
- Scripts take parameters too: Bash `$1`, `"$@"`, `$#`; Python `sys.argv` or `argparse`; PowerShell a `param()` block

```python label="wait_for.py"
import socket
import time

def wait_for(host, port, attempts=5, delay=0.5):
    n = 0
    while n < attempts:
        n += 1
        try:
            socket.create_connection(
                (host, port), timeout=1).close()
            return n             # attempts used
        except OSError:
            time.sleep(delay)
    return None                  # never came up

print(wait_for("127.0.0.1", 18100))
print(wait_for("127.0.0.1", 18101, attempts=2))
```

```console label="Terminal"
$ python3 wait_for.py
1
None
```

- PowerShell parameters validate themselves before the body runs
  - `[Parameter(Mandatory)]`, `[ValidateRange()]`, `[ValidateSet()]`

```powershell label="subnet.ps1"
function Get-Subnet {
    param(
        [Parameter(Mandatory)][string]$Site,
        [ValidateRange(1, 4094)][int]$Vlan = 10
    )
    "$Site VLAN $Vlan -> 10.$Vlan.0.0/24"
}
foreach ($s in 'CLT', 'RDU') { Get-Subnet -Site $s }
Get-Subnet -Site CLT -Vlan 20
Get-Subnet -Site CLT -Vlan 5000
```

```console label="Terminal"
$ pwsh -NoProfile -File subnet.ps1
CLT VLAN 10 -> 10.10.0.0/24
RDU VLAN 10 -> 10.10.0.0/24
CLT VLAN 20 -> 10.20.0.0/24
Get-Subnet: subnet.ps1:10
     | Cannot validate argument on parameter 'Vlan'. The 5000 argument is greater than the maximum allowed range of 4094.
```

- Expect a short script and a question about its output. Trace scope: a Bash variable set in a function without `local` changes the global; a Python assignment in a function creates a new local unless `global` is declared.
- In Bash, `if` tests an exit status, and `0` is success. A distractor will treat `0` as false.
- Parameters are declared, arguments are passed; a `for` loop walks a list, a `while` loop runs until a condition changes.
